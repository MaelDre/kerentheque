Kerentheque est une application de prêt d'objets entre gens de la même ville.
Chaque utilisateur peut:
- lister les objets qu'il accepterait de prêter
- consulter le catalogue d'objets disponible dans la ville.

Pour un objet qu'un utilisateur ajoute comme prêtable, il peut choisir :
- de le rendre publique : il apparaît sur le catalogue publique, tous les utilisateurs verront le nom du propriétaire
- de le rendre privé : il n'apparaît pas sur le catalogue publique.
